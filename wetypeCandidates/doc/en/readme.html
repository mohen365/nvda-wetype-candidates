WeType candidate announcements for NVDA

This NVDA add-on reads the selected candidate exposed by the Windows Text Services Framework (TSF). It does not use OCR, screenshots, network access, clipboard capture, or arrow-count prediction.

Version 0.3.2 was tested with WeType 3.0.0.32 and NVDA 2026.2 on 64-bit Windows. The compact one-row candidate bar is supported. WeType's expanded grid currently returns inconsistent selection data through its TSF interface, so the add-on deliberately stays silent for lists with more than nine candidates.

The native helper is source-available under GPL-2.0-or-later. The included DLL is a convenience build; rebuild it if desired.

Install the add-on from the release file, or copy the globalPlugins/wetypeCandidates directory into the NVDA add-ons directory. Restart NVDA after installation.
